
a - é criado um vetor com o tipo "double" com 5 elementos, um ponteiro *px que aponta para doubles, e um inteiro "i".
o ponteiro px é apontado para o primeiro elemento do vetor x. É feito um for loop no qual é printado o elemento para qual px tá apontando, e logo após incrementado, é uma iteração pelo vetor. Outro for loop é feito, neste caso é feito aritmética de ponteiro para passar pelo vetor, no caso o ponteiro sempre se mantém no elemento[0], e é usado o int i para a aritmética de ponteiros para acessar o valor de interesse..

b - no primeiro modo, px é alterado de valor, em uma iteração é tal valor, em outra é outro valor, etc, ele é modificado diretamente, e deixa de apontar para o inicio do vetor logo na primeira iteração. Já na segunda, é feita aritmética de ponteiros com o indice i indicando o elemento a ser acessado tendo como base o ponteiro px sendo x[0], já que não é preciso mexer nele. Exemplo: px[0] + 3 -> px + 24 -> px[2].

c - é criado um vetor x com 5 elementos, um ponteiro px, um inteiro i, px é apontado para o elemento inicial do vetor x, e dentro do for loop é imprimido o valor apontado por px, e logo após a utilização dele é incrementado para o próximo elemento.
